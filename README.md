# Mises à jour des tablettes Miyora Sushi

Les tablettes lisent `manifest.json` toutes les 30 minutes et s'installent seules la nouvelle carte
ou la nouvelle version de l'appli (la nuit, ou tout de suite si `"immediat": true`).
Les fichiers (APK, carte) sont attachés à la release `maj`. Ne rien mettre de secret ici : ce dépôt est public.
